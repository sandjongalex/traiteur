# Vision — WATO EVENTS

## 1. Positionnement

WATO EVENTS est une entreprise de **traiteur et d'événementiel professionnel à Yaoundé, Cameroun**.

Signature de travail : **« Vos moments, notre savoir-faire. »**

La plateforme numérique doit devenir progressivement le système central de l'activité. Elle ne sera pas une simple vitrine : elle doit soutenir l'acquisition commerciale, la préparation des prestations, l'exécution opérationnelle et le suivi financier.

## 2. Objectifs produit

La plateforme doit permettre à terme de :

- présenter l'entreprise, ses prestations, menus, packs et réalisations ;
- capter des demandes de devis qualifiées ;
- convertir les prospects en clients ;
- gérer clients, événements, devis, commandes et paiements ;
- organiser stocks, fournisseurs, achats, matériel et personnel ;
- suivre la rentabilité ;
- produire des tableaux de bord et rapports.

## 3. Clientèles visées

- particuliers ;
- entreprises ;
- associations ;
- administrations ;
- organisations ;
- organisateurs événementiels.

## 4. Événements couverts

Le système doit gérer une liste de types d'événements administrable, notamment :

- mariage ;
- anniversaire ;
- baptême ;
- réception ;
- cérémonie familiale ;
- réunion ;
- séminaire ;
- conférence ;
- cocktail ;
- buffet ;
- événement d'entreprise ;
- livraison de repas ;
- prestation personnalisée.

Aucun nouveau type d'événement ne doit nécessiter une modification du code source.

## 5. Expérience attendue

### Site public

Le site public doit être :

- mobile first ;
- rapide ;
- responsive ;
- SEO friendly ;
- premium, chaleureux, élégant et moderne ;
- visuellement inspiré d'une identité africaine contemporaine ;
- centré sur la conversion.

### Back-office

Le back-office doit être :

- simple ;
- rapide ;
- orienté productivité ;
- adapté à une utilisation fréquente sur smartphone ;
- sécurisé par rôles et permissions.

## 6. Parcours commercial de référence

VISITEUR → DÉCOUVERTE WATO EVENTS → SERVICES → MENUS / PACKS → CONFIGURATION DU BESOIN → ESTIMATION INDICATIVE → DEMANDE DE DEVIS → PROSPECT → DEVIS → VALIDATION → CLIENT → ÉVÉNEMENT → PAIEMENT → RÉALISATION → CLÔTURE

Cette chaîne guide la conception fonctionnelle et les relations de données.

## 7. Principes métier structurants

- Une estimation en ligne est indicative et ne vaut pas automatiquement devis définitif.
- Une demande doit pouvoir être revue, ajustée puis convertie en devis officiel.
- Un devis accepté peut conduire à la création ou confirmation d'un événement.
- Un événement peut être payé en plusieurs fois.
- Un paiement partiel ne signifie jamais que l'événement est soldé.
- Les mouvements de stock doivent être historisés.
- Le matériel doit distinguer total, disponible, réservé, endommagé et maintenance.
- Les affectations de personnel doivent prendre en compte disponibilité, mission, horaires et coût éventuel.

## 8. Réussite du projet

Le produit sera considéré réussi lorsqu'il permettra à WATO EVENTS de :

1. attirer et convertir des prospects ;
2. centraliser l'information opérationnelle ;
3. réduire les pertes d'information et les doubles saisies ;
4. suivre les engagements clients et paiements ;
5. planifier correctement les ressources ;
6. mesurer la rentabilité des événements ;
7. évoluer sans réécriture majeure de l'architecture.
